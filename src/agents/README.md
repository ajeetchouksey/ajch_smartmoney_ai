# Agents

Autonomous AI agents for SmartMoney Copilot. See [docs/architecture/agents.md](../../docs/architecture/agents.md) for the full design.

## Agents
- `expense_agent/` — Transaction monitoring and categorization
- `budget_agent/` — Budget tracking and forecasting
- `portfolio_agent/` — Portfolio analysis and rebalancing suggestions
- `security_agent/` — Fraud and anomaly detection

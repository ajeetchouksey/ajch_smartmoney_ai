# Backend / API

REST and WebSocket API server for SmartMoney Copilot.

**Planned stack**: Python (FastAPI) or Node.js (Express)

## Services
- `auth/` — Authentication (OAuth 2.0 / OIDC), JWT issuance and validation
- `finance/` — Accounts, transactions, budgets, and portfolio CRUD
- `notifications/` — Push, email, and SMS notification delivery
- `users/` — User profile management and preferences

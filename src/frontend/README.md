# Frontend

Web and mobile application for SmartMoney Copilot.

**Planned stack**: React (web) / React Native (mobile), TailwindCSS

## Key Views
- **Dashboard** — spending overview, portfolio snapshot, upcoming bills
- **Chat (Copilot)** — conversational AI interface
- **Transactions** — searchable, filterable transaction list
- **Budget** — budget setup and progress tracking
- **Portfolio** — investment holdings and performance
- **Alerts** — agent-generated notifications and recommendations
- **Settings** — account, preferences, connected institutions

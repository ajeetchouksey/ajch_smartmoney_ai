# MCP Servers

Model Context Protocol servers for SmartMoney Copilot. See [docs/architecture/mcp-servers.md](../../docs/architecture/mcp-servers.md) for tool definitions.

## Servers
- `transactions/` — Transaction data tools
- `portfolio/` — Portfolio data tools
- `budget/` — Budget management tools
- `market_data/` — Real-time market data tools
